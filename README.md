# Mathnexus · Terminale S2

Parcours interactifs de mathématiques et de sciences physiques pour la **Terminale S2** (programme sénégalais), par Mathnexus Education.

Site : https://alsenytech.github.io/mathnexus-terminale/

- `index.html` : page d'accueil
- `etude-de-fonction.html` : parcours Étude de fonction (partie 1 : domaine et limites)
- `nombres-complexes.html` : parcours Nombres complexes (parties 1 et 2 : forme algébrique, équations), sans les transformations du plan
- `physique/` : site de sciences physiques (P1 Cinématique, P2 Dynamique), avec son générateur et ses séries PDF : voir `physique/README.md`
- `assets/` : MathJax, polices et logo, pour que le site fonctionne aussi sans connexion

Chaque parcours : explications, graphiques interactifs, exercices corrigés type bac, une évaluation chronométrée notée sur 20 à la fin de chaque partie.

## Utilisation hors ligne

Télécharger le dépôt (ou le zip), puis ouvrir `index.html` dans un navigateur.
